Gemini key setup (Bash on RunPod)

This file contains instructions only. Do not put your actual key in this file.

1. Run these commands:

mkdir -p /workspace/private
chmod 700 /workspace/private

2. Run this entire block:

(
  umask 077
  read -rsp "Paste Gemini API key: " gemini_key
  printf '\n'
  printf 'export GEMINI_API_KEY=%q\n' "$gemini_key" > /workspace/private/gemini.env
)
chmod 600 /workspace/private/gemini.env

3. When "Paste Gemini API key:" appears, paste your actual key into the
terminal and press Enter. The key will remain invisible while you paste.
Use the terminal's Edit > Paste or right-click > Paste if needed.

4. Launch Quick Trial from the same terminal:

cd /workspace/Text2TactileGraphics-Code
./launch_quick_trial.sh

For subsequent launches, repeat step 4. Restart an already-running app
after loading the key. The saved key persists while /workspace persists.
Never paste your key into chat or the Gradio UI, or commit it to Git.
