Open a new Bash terminal and paste the entire command block below.
When prompted, paste your Gemini API key, then press Enter.
The pasted key will be invisible. An empty entry will not be saved.
Get a key from Google AI Studio: https://aistudio.google.com/api-keys
Never paste your key into chat.

(
  umask 077
  mkdir -p /workspace/private
  chmod 700 /workspace/private
  read -r -s -p "Paste Gemini API key, then press Enter: " gemini_key < /dev/tty
  printf '\n'
  if [[ -n "$gemini_key" && "$gemini_key" != *[[:space:]]* ]]; then
    printf 'export GEMINI_API_KEY=%q\n' "$gemini_key" > /workspace/private/gemini.env
    chmod 600 /workspace/private/gemini.env
    printf 'Key saved. Tell Codex: key saved.\n'
  else
    printf 'No key saved: input was empty or contained whitespace. Run this block again.\n'
  fi
)

After the terminal says "Key saved", tell Codex "key saved" so it can
restart the UI with the credential and test live prompt planning.
